# Gentle Nutrition Homepage Prototype

This is an early homepage prototype for the Gentle Nutrition project.

## Technologies Used
- HTML
- CSS
- JavaScript

## Current Features
- Homepage navigation
- Discover Products section
- Three paid product placeholders
- Free Constructors offer
- About Us section
- Reviews section
- Help section

## Current Limitations
- Payments are not implemented.
- Product downloads are not implemented.
- Product information is awaiting approval.
